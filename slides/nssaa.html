§16

網路切片專屬認證與授權（NSSAA）

主要認證通過後，部分切片還要用另一組帳密，由 AMF 經 NSSAAF 和 AAA 伺服器跑 EAP 驗證才能使用。

為什麼需要

  • 企業、垂直產業的專用切片，希望自己決定誰能用
  • 主要認證只證明「是電信公司的合法用戶」
  • NSSAA：另一組使用者 ID 與憑證，可由第三方 AAA-S 驗證
  • 被允許的切片只能在主要認證成功後才給

運作流程（1/2）：註冊與判斷

  1. UERegistration Request 附上想用的 S-NSSAI
  2. AMF / SEAF先做主要認證（已有有效上下文可略過）
  3. AMF逐一判斷各 S-NSSAI 要不要 NSSAA，送 Registration Accept
  4. AMF經 NAS MM Transport 要 EAP ID，UE 回傳

運作流程（2/2）：EAP 認證

  1. AMF → NSSAAF送 EAP ID、GPSI、S-NSSAI，依切片轉給 AAA-S
  2. AAA-S記下 GPSI 與 EAP ID 的對應
  3. UE ↔ AAA-S來回交換 EAP，結果送回 UE
  4. AMF更新 Allowed／Rejected NSSAI；未完成就記狀態下次重做

白話解釋

進科技園區大門要刷園區識別證（主要認證），但有些公司辦公室門口還有自己的門禁，要用公司帳號再登入一次（NSSAA）。

放不放行由公司伺服器（AAA-S）決定，管理處（AMF、NSSAAF）只轉交；公司也能隨時要求重刷或註銷權限。

常見考點（1/3）

  • 和主要認證差在哪？選用、針對切片、另一組憑證、AAA-S 驗證
  • 能先拿切片再認證嗎？不行，主要認證成功後才給
  • 誰是 EAP authenticator？SEAF／AMF，經 NSSAAF 轉換協定

常見考點（2/3）

  • EAP ID 隱私？建議用具隱私保護能力的 EAP 方法
  • AAA-S 怎麼找到 UE？用 GPSI，NSSAAF 向 UDM 查服務的 AMF
  • 任何 AAA 都能撤銷？不行，NSSAAF 依 S-NSSAI 對應的 AAA-S 位址檢查

常見考點（3/3）

  • 撤銷後怎樣？移到 Rejected；沒切片可用就給 Default 或註銷
  • 第二種接取要重做嗎？不一定，AMF 可依政策略過
  • 中途失敗？AMF 記下狀態，下次註冊時重做
