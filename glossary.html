術語表

所有主題頁出現過的縮寫，依英文字母排序，點出處可回到原頁面。

5G-AKA 5G Authentication and Key Agreement
5G 的主要認證方法之一，最終由 home network 確認認證結果。出處：5G-AKA 認證
5G-GUTI 5G Globally Unique Temporary Identifier
網路分配的臨時身分，日常通訊用它取代永久身分。出處：SUPI 隱藏與 SUCI
ARPF Authentication credential Repository and Processing Function
位在 UDM 裡，保存長期金鑰 K 並產生認證向量。出處：5G-AKA 認證
AUSF Authentication Server Function
home network 的認證伺服器，負責最終比對手機回應。出處：5G-AKA 認證
AUTN Authentication Token
讓 USIM 確認考題來自 home network 且不是舊的。出處：5G-AKA 認證
ECIES Elliptic Curve Integrated Encryption Scheme
先用 ECDH 算共享金鑰、再用對稱加密保護資料的混合加密法。出處：SUPI 隱藏與 SUCI
HXRES* Hash of XRES*
標準答案 XRES* 的雜湊值，讓 SEAF 初步比對卻拿不到答案。出處：5G-AKA 認證
KAUSF Key for AUSF
由 CK、IK 推導出、存放在 AUSF 的金鑰，是 KSEAF 的上一層。出處：5G-AKA 認證
KSEAF Key for SEAF
服務網路的錨點金鑰，認證成功後才交給 SEAF，再推導出 KAMF。出處：5G-AKA 認證
RAND Random Challenge
網路出給手機的隨機考題。出處：5G-AKA 認證
RES* Response
手機由 RES 與服務網路名稱推導出的答案，對應的標準答案是 XRES*。出處：5G-AKA 認證
SEAF Security Anchor Function
位在 AMF 裡，向手機發起認證並初步比對答案。出處：5G-AKA 認證
SIDF Subscription Identifier De-concealing Function
位在 UDM 內、持有私鑰，負責把 SUCI 解回 SUPI。出處：SUPI 隱藏與 SUCI
SUCI Subscription Concealed Identifier
SUPI 加密後的版本，可安全地在空中介面傳送。出處：SUPI 隱藏與 SUCI
SUPI Subscription Permanent Identifier
用戶永久身分，常見格式為 IMSI。出處：SUPI 隱藏與 SUCI
UDM Unified Data Management
home network 的用戶資料中心，內含 ARPF 與 SIDF。出處：5G-AKA 認證
