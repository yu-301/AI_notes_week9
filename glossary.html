術語表

所有主題頁出現過的縮寫，依英文字母排序，點出處可回到原頁面。

5G-AKA 5G Authentication and Key Agreement
5G 的主要認證方法之一，最終由 home network 確認認證結果。出處：5G-AKA 認證
5G-GUTI 5G Globally Unique Temporary Identifier
網路分配的臨時身分，日常通訊用它取代永久身分。出處：SUPI 隱藏與 SUCI
AAA-P AAA Proxy
營運商通往第三方 AAA 伺服器時使用的代理，可和 NSSAAF 合併部署。出處：網路切片專屬認證與授權（NSSAA）
AAA-S AAA Server
執行切片專屬認證的 AAA 伺服器，可能屬於第三方企業。出處：網路切片專屬認證與授權（NSSAA）
ABBA Anti-Bidding down Between Architectures
SEAF 送給 UE 的參數，防止安全功能被降級，也用來推導 KAMF。出處：EAP-AKA' 認證
ARPF Authentication credential Repository and Processing Function
位在 UDM 裡，保存長期金鑰 K 並產生認證向量。出處：5G-AKA 認證
AS Access Stratum
UE 與基地台之間的接取層，安全涵蓋 RRC 訊號與使用者面資料。出處：安全演算法選擇與安全模式命令程序
AUSF Authentication Server Function
home network 的認證伺服器，負責最終比對手機回應。出處：5G-AKA 認證
AUTN Authentication Token
讓 USIM 確認考題來自 home network 且不是舊的。出處：5G-AKA 認證
CCA Client Credentials Assertion
服務使用者自己簽的短效 JWS 聲明，經過 SCP 時用來證明身分。出處：服務化架構的網路功能授權（OAuth 2.0）
DRB Data Radio Bearer
空中介面上承載使用者資料的無線承載，UP 保護逐條 DRB 啟用。出處：使用者平面（UP）安全與完整性保護
EAP Extensible Authentication Protocol
可承載各種認證方法的通用認證框架。出處：EAP-AKA' 認證
EAP-AKA' Improved Extensible Authentication Protocol Method for 3rd Generation Authentication and Key Agreement
在 EAP 框架裡執行的 AKA，是 5G 兩種主要認證方法之一。出處：EAP-AKA' 認證
ECIES Elliptic Curve Integrated Encryption Scheme
先用 ECDH 算共享金鑰、再用對稱加密保護資料的混合加密法。出處：SUPI 隱藏與 SUCI
EMSK Extended Master Session Key
EAP-AKA' 由 CK'、IK' 推導出的金鑰，取最高 256 bits 當 KAUSF。出處：EAP-AKA' 認證
ENSI External Network Slice Information
送給第三方 AAA-S 時，用來取代 S-NSSAI 的對外切片資訊。出處：網路切片專屬認證與授權（NSSAA）
GPSI Generic Public Subscription Identifier
用戶的公開識別碼；AAA-S 用它要求重新認證或撤銷切片授權。出處：網路切片專屬認證與授權（NSSAA）
HXRES* Hash of XRES*
標準答案 XRES* 的雜湊值，讓 SEAF 初步比對卻拿不到答案。出處：5G-AKA 認證
IPX IP exchange service
營運商之間的互連服務業者，是一種漫遊中介（RI）。出處：SEPP 與 N32 介面的漫遊安全
JWE JSON Web Encryption
SEPP 之間用共享金鑰同時加密與完整性保護 N32-f 訊息的 JSON 格式。出處：SEPP 與 N32 介面的漫遊安全
JWS JSON Web Signature
漫遊中介用私鑰簽署自己對訊息所做修改的 JSON 格式。出處：SEPP 與 N32 介面的漫遊安全
JWT JSON Web Token
5G access token 的格式，用 JWS 簽章或 MAC 保護。出處：服務化架構的網路功能授權（OAuth 2.0）
KAMF Key for AMF
AMF 的根金鑰，由 KSEAF 推出，NAS 金鑰與 KgNB 都從它推導。出處：5G 金鑰階層與金鑰推導
KAUSF Key for AUSF
由 CK、IK 推導出、存放在 AUSF 的金鑰，是 KSEAF 的上一層。出處：5G-AKA 認證
KDF Key Derivation Function
單向的金鑰推導函數，下層金鑰推不回上層金鑰。出處：5G 金鑰階層與金鑰推導
KgNB Key for gNB
基地台的根金鑰，由 KAMF 推出，再推導出 RRC 與 UP 金鑰。出處：5G 金鑰階層與金鑰推導
KNG-RAN* Key for target NG-RAN node
換手時由目前 KgNB 或 NH 推出、給目標基地台當新 KgNB 的金鑰。出處：換手時的安全處理與金鑰推導
KSEAF Key for SEAF
服務網路的錨點金鑰，認證成功後才交給 SEAF，再推導出 KAMF。出處：5G-AKA 認證
KUPenc UP encryption key
由 KgNB 推出的使用者平面加密金鑰。出處：使用者平面（UP）安全與完整性保護
KUPint UP integrity key
由 KgNB 推出的使用者平面完整性金鑰。出處：使用者平面（UP）安全與完整性保護
LSM Limited Service Mode
受限服務模式；未認證 UE 做緊急通話時只能用空演算法。出處：安全演算法選擇與安全模式命令程序
MAC-I Message Authentication Code for Integrity
PDCP 封包裡的完整性驗證碼，未啟用 UP 完整性時不放。出處：使用者平面（UP）安全與完整性保護
N32 N32 interface
兩個 SEPP 之間的介面，分成管理用的 N32-c 與轉送訊令的 N32-f。出處：SEPP 與 N32 介面的漫遊安全
NAS Non Access Stratum
UE 與 AMF 之間的控制訊號層，負責註冊、移動管理等。出處：NAS 安全機制
NAS COUNT NAS Count
16-bit NAS OVERFLOW 加 8-bit NAS SQN 的計數器，用來防重放。出處：NAS 安全機制
NAS-MAC NAS Message Authentication Code
用 NIA 對 NAS 訊息算出的 32-bit 驗證碼。出處：NAS 安全機制
NASC NAS Container
N2 換手時目標 AMF 經 HO Command 送給 UE 的 NAS 參數包，作用類似 NAS SMC。出處：換手時的安全處理與金鑰推導
NCC Next hop Chaining Counter
NH 鏈的編號，UE 靠它判斷換手時該做水平還是垂直推導。出處：換手時的安全處理與金鑰推導
NEA Encryption Algorithm for 5G
5G 的加密演算法，128-NEA1～3；NEA0 為不加密的空演算法。出處：NAS 安全機制
ngKSI Key Set Identifier in 5G
KAMF 的識別碼，讓 UE 與 AMF 不用重新認證就能指認安全上下文。出處：5G 金鑰階層與金鑰推導
NH Next Hop
AMF 推出的中間金鑰，換手時用來產生新的 KgNB，提供前向安全。出處：5G 金鑰階層與金鑰推導
NIA Integrity Algorithm for 5G
5G 的完整性演算法，128-NIA1～3；NIA0 為不保護的空演算法。出處：NAS 安全機制
NRF Network Repository Function
網元註冊與探索中心，也是簽發 access token 的 OAuth 2.0 授權伺服器。出處：服務化架構的網路功能授權（OAuth 2.0）
NSSAA Network Slice Specific Authentication and Authorization
主要認證之後，針對特定切片的額外 EAP 認證與授權。出處：網路切片專屬認證與授權（NSSAA）
NSSAAF Network Slice-Specific and SNPN Authentication and Authorization Function
把 NSSAA 請求送到對應 AAA-S，並轉換服務化訊息與 AAA 協定的網元。出處：網路切片專屬認證與授權（NSSAA）
OAuth 2.0 OAuth 2.0 Authorization Framework
標準授權框架；5G 用 Client Credentials Grant 讓網元換取存取權杖。出處：服務化架構的網路功能授權（OAuth 2.0）
PCI Physical Cell Identity
目標 cell 的實體識別碼，換手推導新金鑰時會綁進去。出處：換手時的安全處理與金鑰推導
PDCP Packet Data Convergence Protocol
UE 與基地台間負責 UP 加密與完整性保護的協定層。出處：使用者平面（UP）安全與完整性保護
PRINS PRotocol for N32 INterconnect Security
N32-f 的應用層安全協定：SEPP 用 JWE 加密，RI 用 JWS 簽修改。出處：SEPP 與 N32 介面的漫遊安全
RAND Random Challenge
網路出給手機的隨機考題。出處：5G-AKA 認證
RES* Response
手機由 RES 與服務網路名稱推導出的答案，對應的標準答案是 XRES*。出處：5G-AKA 認證
RI Roaming Intermediary
兩家營運商之間的漫遊中介，例如 IPX 或漫遊樞紐。出處：SEPP 與 N32 介面的漫遊安全
RRC Radio Resource Control
UE 與基地台之間的控制訊號，例如建立連線、換手指令。出處：安全演算法選擇與安全模式命令程序
S-NSSAI Single Network Slice Selection Assistance Information
一個網路切片的識別碼。出處：網路切片專屬認證與授權（NSSAA）
SBA Service Based Architecture
服務化架構：核心網元以 HTTP API 提供與使用服務。出處：服務化架構的網路功能授權（OAuth 2.0）
SCP Service Communication Proxy
間接通訊時替網元轉送請求、可代為探索服務提供者的代理。出處：服務化架構的網路功能授權（OAuth 2.0）
SEAF Security Anchor Function
位在 AMF 裡，向手機發起認證並初步比對答案。出處：5G-AKA 認證
SEPP Security Edge Protection Proxy
網路邊界的安全代理，所有跨營運商的控制面訊令都經過它。出處：SEPP 與 N32 介面的漫遊安全
SIDF Subscription Identifier De-concealing Function
位在 UDM 內、持有私鑰，負責把 SUCI 解回 SUPI。出處：SUPI 隱藏與 SUCI
SMC Security Mode Command
選定演算法並啟動安全保護的程序，NAS 與 AS 各有一個。出處：NAS 安全機制
SMF Session Management Function
管理 PDU session 的核心網元，負責下達 UP 安全政策。出處：使用者平面（UP）安全與完整性保護
SUCI Subscription Concealed Identifier
SUPI 加密後的版本，可安全地在空中介面傳送。出處：SUPI 隱藏與 SUCI
SUPI Subscription Permanent Identifier
用戶永久身分，常見格式為 IMSI。出處：SUPI 隱藏與 SUCI
UDM Unified Data Management
home network 的用戶資料中心，內含 ARPF 與 SIDF。出處：5G-AKA 認證
UP User Plane
使用者平面，承載使用者真正傳送的資料。出處：使用者平面（UP）安全與完整性保護
