術語表

所有主題頁出現過的縮寫，依英文字母排序，點出處可回到原頁面。

5G-AKA 5G Authentication and Key Agreement
5G 的主要認證方法之一，最終由 home network 確認認證結果。出處：5G-AKA 認證
5G-GUTI 5G Globally Unique Temporary Identifier
網路分配的臨時身分，日常通訊用它取代永久身分。出處：SUPI 隱藏與 SUCI
ABBA Anti-Bidding down Between Architectures
SEAF 送給 UE 的參數，防止安全功能被降級，也用來推導 KAMF。出處：EAP-AKA' 認證
ARPF Authentication credential Repository and Processing Function
位在 UDM 裡，保存長期金鑰 K 並產生認證向量。出處：5G-AKA 認證
AUSF Authentication Server Function
home network 的認證伺服器，負責最終比對手機回應。出處：5G-AKA 認證
AUTN Authentication Token
讓 USIM 確認考題來自 home network 且不是舊的。出處：5G-AKA 認證
EAP Extensible Authentication Protocol
可承載各種認證方法的通用認證框架。出處：EAP-AKA' 認證
EAP-AKA' Improved Extensible Authentication Protocol Method for 3rd Generation Authentication and Key Agreement
在 EAP 框架裡執行的 AKA，是 5G 兩種主要認證方法之一。出處：EAP-AKA' 認證
ECIES Elliptic Curve Integrated Encryption Scheme
先用 ECDH 算共享金鑰、再用對稱加密保護資料的混合加密法。出處：SUPI 隱藏與 SUCI
EMSK Extended Master Session Key
EAP-AKA' 由 CK'、IK' 推導出的金鑰，取最高 256 bits 當 KAUSF。出處：EAP-AKA' 認證
HXRES* Hash of XRES*
標準答案 XRES* 的雜湊值，讓 SEAF 初步比對卻拿不到答案。出處：5G-AKA 認證
KAMF Key for AMF
AMF 的根金鑰，由 KSEAF 推出，NAS 金鑰與 KgNB 都從它推導。出處：5G 金鑰階層與金鑰推導
KAUSF Key for AUSF
由 CK、IK 推導出、存放在 AUSF 的金鑰，是 KSEAF 的上一層。出處：5G-AKA 認證
KDF Key Derivation Function
單向的金鑰推導函數，下層金鑰推不回上層金鑰。出處：5G 金鑰階層與金鑰推導
KgNB Key for gNB
基地台的根金鑰，由 KAMF 推出，再推導出 RRC 與 UP 金鑰。出處：5G 金鑰階層與金鑰推導
KSEAF Key for SEAF
服務網路的錨點金鑰，認證成功後才交給 SEAF，再推導出 KAMF。出處：5G-AKA 認證
NAS Non Access Stratum
UE 與 AMF 之間的控制訊號層，負責註冊、移動管理等。出處：NAS 安全機制
NAS COUNT NAS Count
16-bit NAS OVERFLOW 加 8-bit NAS SQN 的計數器，用來防重放。出處：NAS 安全機制
NAS-MAC NAS Message Authentication Code
用 NIA 對 NAS 訊息算出的 32-bit 驗證碼。出處：NAS 安全機制
NEA Encryption Algorithm for 5G
5G 的加密演算法，128-NEA1～3；NEA0 為不加密的空演算法。出處：NAS 安全機制
ngKSI Key Set Identifier in 5G
KAMF 的識別碼，讓 UE 與 AMF 不用重新認證就能指認安全上下文。出處：5G 金鑰階層與金鑰推導
NH Next Hop
AMF 推出的中間金鑰，換手時用來產生新的 KgNB，提供前向安全。出處：5G 金鑰階層與金鑰推導
NIA Integrity Algorithm for 5G
5G 的完整性演算法，128-NIA1～3；NIA0 為不保護的空演算法。出處：NAS 安全機制
RAND Random Challenge
網路出給手機的隨機考題。出處：5G-AKA 認證
RES* Response
手機由 RES 與服務網路名稱推導出的答案，對應的標準答案是 XRES*。出處：5G-AKA 認證
SEAF Security Anchor Function
位在 AMF 裡，向手機發起認證並初步比對答案。出處：5G-AKA 認證
SIDF Subscription Identifier De-concealing Function
位在 UDM 內、持有私鑰，負責把 SUCI 解回 SUPI。出處：SUPI 隱藏與 SUCI
SMC Security Mode Command
選定演算法並啟動安全保護的程序，NAS 與 AS 各有一個。出處：NAS 安全機制
SUCI Subscription Concealed Identifier
SUPI 加密後的版本，可安全地在空中介面傳送。出處：SUPI 隱藏與 SUCI
SUPI Subscription Permanent Identifier
用戶永久身分，常見格式為 IMSI。出處：SUPI 隱藏與 SUCI
UDM Unified Data Management
home network 的用戶資料中心，內含 ARPF 與 SIDF。出處：5G-AKA 認證
