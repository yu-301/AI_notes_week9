§6.1.3.1

EAP-AKA' 認證

把 AKA 包進 EAP 框架：SEAF 只轉送，由 home network 的 AUSF 當 EAP 伺服器驗證。

TS 33.501 Rel-18｜更新於 2026-11-03

看簡報版

為什麼需要

5G 的核心網路希望不管手機從哪種接取網路進來（3GPP 的基地台，或 Wi-Fi 等非 3GPP 接取），都用同一套認證方式。可擴充認證協定（Extensible Authentication Protocol，EAP）本來就是通用的認證框架，所以 5G 把它列為主要認證的選項之一。

在 4G，EAP-AKA' 主要用在可信任的非 3GPP 接取（TS 33.402），3GPP 接取則用 EPS-AKA，認證結果由拜訪網路的 MME 決定。到了 5G，UE 和服務網路都必須同時支援 EAP-AKA' 和 5G-AKA，要用哪一種由 home network 業者決定（§6.1.1.1）。

EAP-AKA' 天生就由 home network 的 AUSF 擔任 EAP 伺服器、親自比對手機的回應，所以和 5G-AKA 一樣具備「增加 home network 控制」的效果（§6.1.4.1）。

運作流程

  1. UDM/ARPF產生 AMF separation bit 為 1 的認證向量，再依 Annex A.3 算出 CK'、IK'，取代原本的 CK、IK。
  2. UDM把 AV'（RAND、AUTN、XRES、CK'、IK'）回給 AUSF，並註明要用於 EAP-AKA'；若當初收到的是 SUCI，也一併附上 SUPI。
  3. AUSF產生 EAP-Request/AKA'-Challenge，放在 Nausf_UEAuthentication_Authenticate Response 裡送給 SEAF。
  4. SEAF把 EAP 訊息原封不動放進 NAS Authentication Request 轉給 UE，並附上 ngKSI 與 ABBA。
  5. UE（USIM + ME）USIM 驗證 AUTN 的新鮮度，算出 RES、CK、IK；ME 再依 Annex A.3 推導出 CK'、IK'。AUTN 驗證失敗則依 §6.1.3.3 處理。
  6. UE → SEAF → AUSFUE 以 NAS 訊息回傳 EAP-Response/AKA'-Challenge，SEAF 同樣透明轉送給 AUSF。
  7. AUSF比對 RES 與 XRES，失敗就回錯誤給 SEAF；成功就把認證結果通知 UDM（§6.1.4）。雙方也可以再交換 EAP Notification 訊息。
  8. AUSF由 CK'、IK' 推導出 EMSK，取最高 256 bits 當 KAUSF，再推出 KSEAF（Annex A.6）。接著把 EAP Success 與 KSEAF（若當初用 SUCI，也附上 SUPI）送給 SEAF。
  9. SEAF / UESEAF 把 EAP Success 連同 ngKSI、ABBA 轉給 UE，並由 KSEAF、ABBA、SUPI 推導 KAMF 交給 AMF。UE 收到 EAP Success 後，用同樣方式推出 KAUSF、KSEAF、KAMF。

白話解釋

延續 5G-AKA 那頁的比喻：5G-AKA 的分公司手上有「標準答案的指紋」，會先幫忙看一眼你的答案。EAP-AKA' 的分公司則只是郵差，總公司寄來的考卷是密封的，你寫完的答卷也原封不動寄回總公司。

總公司親自批改，合格就寄回「合格通知」（EAP Success）和分公司用的門禁卡（KSEAF）。分公司從頭到尾都看不懂考卷內容，只負責轉交。

常見考點

  • EAP 的三種角色在 5G 分別是誰？UE 是 peer，SEAF 是 pass-through authenticator，AUSF 是 backend authentication server，也就是 EAP 伺服器（§6.1.1.2）。
  • EAP-AKA' 和 5G-AKA 中，SEAF 的角色有什麼不同？EAP-AKA' 的 SEAF 只透明轉送 EAP 訊息，不做任何比對；5G-AKA 的 SEAF 拿到 HXRES*，可以先用 HRES* 做初步比對。
  • 兩者的 KAUSF 怎麼產生？EAP-AKA' 由 CK'、IK' 推出 EMSK，取最高 256 bits；5G-AKA 直接用 CK||IK 加上服務網路名稱經 KDF 推導（Annex A.2）。
  • 兩者的服務網路名稱綁定在哪裡？EAP-AKA' 綁在 CK'、IK' 的推導（Annex A.3），透過 AT_KDF_INPUT 攜帶；5G-AKA 綁在 RES*、KAUSF、KSEAF 的推導。
  • 兩者都有 increased home control 嗎？都有。EAP-AKA' 在 AUSF 驗證 EAP-Response/AKA'-Challenge 成功時確認；5G-AKA 在 AUSF 驗證 RES* 認證確認成功時確認，之後都要通知 UDM（§6.1.4.1）。
  • 誰決定要用哪一種？home network 業者決定，由 UDM/ARPF 依 SUPI 選擇；UE 和服務網路兩種都必須支援（§6.1.1.1、§6.1.2）。
  • 5G 支援 EAP-AKA' 的 fast re-authentication 嗎？不支援（Annex F.3）。
